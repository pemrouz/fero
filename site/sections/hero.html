Shared live objects for Node

Plain assignment replicates.

await fero(name) gives you a live object. Read it like a plain object. Change it by plain assignment. Every process that opens the same name sees the same object, on one box or across a cluster.

Its examples build a chat room, a kanban board and a ledger. This page runs a tiny cat café.

import { fero } from 'fero'

const cafe = await fero('cafe')
// every copy hears luna purr
cafe.data.luna = { mood: 'purring' }
$ npm i fero Start in two files ↓ GitHub

One client's copy, from fero's real kernel in your tab. This client sets luna's mood every few seconds.
