    This is fero's kernel: the same kernel files its TCP shell runs, with the types stripped. A simulator gives it a network, disks and a clock, and "the kernel cannot tell it isn't on a real network; that is the design" (sim/exec.ts). The page cannot call fero() itself, because that needs Node's sockets and files. So a write here posts the record an assignment becomes: shop.data.gadgets = { stock: … } is { type: … }. Times are on the simulated clock, and links are set to — so a write is slow enough to watch. Each slanted line is one message, drawn at its real send and arrival times. A crashed server is voted out when the others' redials give up: — at redial —, and — at fero's defaults (own runs, seeded from the dock). Every other number is read from the kernel as it runs.
