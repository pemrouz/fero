    Break it
    
      
    A cluster earns trust on its bad days. Below are three runs of fero’s kernel, each in its own simulator, from the same seed as the cluster above. In each, the client makes the same write just after a server is crashed or asked to stop: crashed, stopped cleanly, or crashed when only two servers are left. The line under each run is its view over time, and the amber bar is how long the write waited.

    Each run is a separate simulation, so nothing here touches the cluster above. A crash waits: the survivors redial the dead server until they give up, and only then vote. A clean stop asks for its own vote, so it is gone almost at once. With two servers, the one left is not a majority. It cannot vote the dead one out, so the write waits until the page restarts the dead server from its disk. Times are on the simulated clock.
