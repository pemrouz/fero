one assignment, one record

Plain assignment replicates.

await fero(name) gives you a live object. Read it like a plain object. Change it by plain assignment. Derive live views from it. Every process that opens the same name sees the same object, on one box or across a cluster.

fero's own examples build a shop, a chat room, a kanban board and a ledger. Each row (a top-level key) has one owner: the one server that stamps its writes. Your assignment becomes one record. The owner gives it a stamp: the number of the view (the agreed list of servers, which only a vote changes), a counter and its name. Then the record lands on every copy. Nothing shows before it commits, and nothing merges.

one row, one writer

Kill the owner.
The write still lands.

Each row (a top-level key) has one owner: the one server that stamps its writes. Kill it, and a write to its row waits. Nothing shows early.

The other servers vote the dead one out: a new view (the agreed list of servers). A survivor takes the row and gives the write its stamp: the view number, a counter and its name. The write lands on every live copy. That needs a majority: two servers cannot survive a crash, so run three.
