Every kernel event is a line in a node's journal. fero's debugger reads those lines in order and builds views from them: where each write went, where a node set a write aside, and what every node held at any moment. Before it draws, it replays the journals and checks that they rebuild every node's end state exactly.

This card runs the debugger's own file, model.mjs, without a change, over the cluster above. Drag its time bar and every node rewinds.

  • replayverifyReplayrebuilds each node from its whole journal. If one cell differs, the card draws nothing.
  • writesrouteswhere each write went: origin (stamped there), applied, lww-lost (lost to a bigger stamp: the last writer wins), duplicate or never-arrived (not there yet).
  • racescontestedthe cells where a node set a write aside, because a bigger stamp was already there.
  • rewindstateAta node's state after one line of its journal. The time bar uses it to rewind every node.
