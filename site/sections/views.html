How this runs in your tab

This page loads the data library from npm when you scroll here.

fero's kernel runs here too, on a simulated network. The page cannot run fero() itself (that needs Node's sockets), so client c1 posts the record each assignment becomes. The library starts from that client's copy, then takes every change that reaches it through lane(), the same call fero makes when a change reaches a copy.

After every change, the page also checks each cat in that copy by hand, in plain JavaScript, and compares the rows with the filter's.
