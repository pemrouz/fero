fero debugging — information architecture map

The atom is one commit (change record {type, key, value, origin, seq, epoch}). A partition = the top-level segment of a dotted key (user42 for user42.score) and holds many keys; the log, ownership and replication are all per-partition — so the partition page is the log, and a key is a lens on it.

Two co-equal spines from a resource: data (partitions → log) and physical (server + client nodes), which meet at the partition page. Epoch is a dimension across ownership/node views (now, expandable to prior epochs). Metrics cross-cut every level. Several levels need NEW instrumentation (historical-epoch layouts, per-partition latency/throughput) — flagged per level.
