Data sources — how this nodes table is assembled

Per node. Current-epoch ownership (owns) from snapshot ring.coverage [A]. keys (under this node's ownership) & writes/s are aggregated from each owned partition's log.heads / the __observe per-second rollup [A][B]. max lag is the worst per-partition replication lag this node carries, from snapshot marks/heads vs the floor [A].

DIVERGED / LAGGING status is rolled up from the node's partitions: diverged = it owns (or holds) a stale value, which needs the ⚠ NEW per-key version sample __inspect{versions:K} cross-merged on node uuid [A]; lagging = a replica it hosts is behind on the log and serving stale reads [A]. Per-epoch ownership history (the node page) is ⚠ NEW — fero retains only the current ring state, not historical layouts. The per-partition detail lives one level over, on partitions.html / the partition log.
