Data sources — how this resources table is assembled

One row per fero(name). The set of running resources comes from the DHT registry / each member's advertised resources [A]. members & partitions from snapshot ring.coverage; keys from each partition's log.heads; writes/s from the __observe per-second rollup, summed across the resource [A][B].

DIVERGED / UNDER / CONTENDED status is the worst per-resource rollup of its partitions (see the partitions table one level down): diverged needs the ⚠ NEW per-key version sample __inspect{versions:K} cross-merged on node uuid [A]; under-replicated from snapshot orphans + the cover diff [A][E]; contended from __observe lost events filtered to we=epoch (same-epoch) [B].
