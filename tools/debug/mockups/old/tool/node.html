Data sources — how this node view is assembled

Owns @ e4 (centre). The node's current owned-set from snapshot ring.coverage; per-partition held/R from the cover diff vs R, keys/w/s from each partition's log.heads / __observe rollup [A][B].

Ownership by epoch (left). ⚠ NEW — fero retains only the current ring layout, not historical ownership. The e4←e3←e2←e1 set (and the gains/losses at each view change) is newly recorded; today only the e4 column is derivable from ring.coverage.

Replicates (centre). The copies this node hosts as a non-owner; per-replica lag from snapshot marks/heads vs the floor [A]. A stuck replica that still serves reads (it never adopted the newer view) is the divergence the owning partition's log explains.
