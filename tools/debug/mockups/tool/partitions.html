Data sources — how this partitions table is assembled

Per partition. Owner from snapshot ring.coverage; replicas (held/R) from coverage vs R [A]. Under-replication / orphan from snapshot orphans + the cover diff [A][E]. keys (the count a partition holds) & log size from log.heads / log.size [A]. writes/s from the __observe per-second rollup [B].

DIVERGED / CONTENDED status is rolled up from the partition's keys: a partition is flagged diverged when any key in it diverges, which needs the ⚠ NEW per-key version sample __inspect{versions:K} cross-merged on node uuid [A] — fero exposes converged state, not a replica-by-replica value diff. contended vs fence comes from __observe's lost events filtered to we=epoch (same-epoch) [B]. The per-key detail (stamp, agreement, the log) lives one level down, on the partition's log page.
