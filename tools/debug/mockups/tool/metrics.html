Data sources — how these metrics are assembled

Rates (cards). writes/s & conflicts/s from the __observe per-second rollup; requests/s from the transport's per-member RPC counters [B][D]. reads/s is ⚠ NEW — read/subscription delivery is not counted today.

Latency (p50 / p99). ⚠ NEW — fero exposes cluster-wide rollups, not per-scope commit / replicate / read p50·p99. This whole panel is proposed instrumentation: commit = owner append→ack, replicate = owner→replica apply, read = subscription delivery.

Slicing. The same series re-scoped to a resource, a partition (its replicas), or a node (its owned partitions). Per-node and per-partition throughput/latency are ⚠ NEW — only cluster and __observe resource rollups exist today. Time series are sliceable by epoch to overlay view changes.
