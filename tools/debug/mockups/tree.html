Data sources — one model, every level

This page renders the whole cluster from a SINGLE dataset — resources, partitions, nodes, clients, epochs and commits are one graph, so a stat can't disagree with itself across views (the cross-page drift the multi-page tool had to audit for is impossible here).

Per level. Resources from the DHT registry; partitions/ownership from ring.coverage; replica lag from snapshot marks/heads vs the floor; the log from log.recordsSince; divergence from the ⚠ NEW per-key version sample __inspect{versions:K}; contention from __observe lost events.

Filtering prunes the tree to branches containing a match and auto-expands to reveal them — one query spanning every resource/partition/node at once. Per-client telemetry and owner-by-epoch history are ⚠ NEW (not retained today).
